# Menú de restaurante

## Resumen

Ejercicio de maquetación para un restaurante. Reúne una portada, una sección de servicios y una cuadrícula de platos.

## Cómo verlo

Abre [index.html](index.html) para recorrer la portada y el menú. La distribución y las reglas adaptables están en [style.css](style.css).

## English summary

A restaurant layout exercise with a hero section, a services section, and a grid of dishes.
